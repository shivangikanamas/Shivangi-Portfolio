# Shivangi — Java & DevOps Portfolio

A standalone, responsive portfolio website for an aspiring DevOps engineer. Built with plain HTML, CSS and JavaScript; no build tools, packages, cloud accounts, or credentials are needed to preview it.

## View the portfolio

After publishing GitHub Pages, open:

**https://shivangikanamas.github.io/Shivangi-Portfolio/**

## Preview locally

Open `index.html` in a browser. To serve it locally, from this folder run:

```powershell
python -m http.server 8000
```

Then visit http://localhost:8000.

## Portfolio content

- Introduction to Shivangi's growing interest in Java, cloud infrastructure and DevOps.
- A categorized overview of the technologies explored in the featured project.
- A custom task-board preview linking to the task manager's interactive demo and source code.
- Responsive navigation, keyboard-accessible mobile menu and reduced-motion support.

The site describes the technologies as explored through a portfolio project; it does not claim professional experience or imply that the example AWS infrastructure is deployed. The featured task manager's hosted preview is a browser-based demo, not a live AWS backend. Update the content as your experience grows.
